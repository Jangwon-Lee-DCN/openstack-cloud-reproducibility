Lifecycle operations

  • Resize Cluster changes the default-worker MachineDeployment through Magnum.
  • Rolling Kubernetes Upgrade selects a compatible newer template and controls batch size.
  • Rotate Credentials rolls workload credentials; use only while the cluster is stable.
  • Mutating actions are unsafe while another reconciliation is in progress.

Diagnosis and recovery

  1. Read the failed timeline phase and latest reconcile message.
  2. Verify Git/Argo ownership before changing infrastructure.
  3. Retry through the Magnum action that owns the resource.
  4. Delete only after checking load balancers, volumes and floating IP dependencies.
Automatic repair is intentionally not started from this view. Review the reported dependency first.
